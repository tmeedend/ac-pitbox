# Media of the sample story

Every file of this folder, where it comes from and under which licence it may
be redistributed. The sample is copied by authors into their own stories
(Copy the sample), so its media must be free to reuse there: the project's own
work under CC0, or a third-party file under CC0 or a licence that allows it
(SPEC-story-mode, Engine file format: the sample shows how everything is
made). No brand, logo, real person or real story.

A file added to this folder gets its line here in the same commit, until the
editor records each asset's origin and licence itself (SPEC-story-mode,
Scenes, frame and sound: assets come from anywhere).
